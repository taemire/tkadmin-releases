AI DDR SIEM 연동

정보

BL-027은 AI DDR finding을 내부 감사 로그(source='aiddr')와 외부 SIEM(Syslog, CEF, Webhook)으로 전파합니다. BL-032부터 Syslog 재시도 backoff와 queue full 감사 경고가 적용됩니다. 기본값은 비활성입니다.

활성화​

ai.logai.enabled, ai.aiddr.enabled, ai.aiddr.alert.enabled를 모두 true로 설정한 뒤 필요한 sink를 켭니다. Webhook secret 누락이나 Syslog TLS 인증서 누락처럼 운영자가 즉시 알아야 하는 설정 오류는 startup 실패로 처리됩니다.

cfg 예제​

ai:
  aiddr:
    alert:
      enabled: true
      dedup_window_min: 5
      dedup_lru_size: 10000
      queue_size: 1024
      workers: 4
      queue_full_threshold: 100
      sinks:
        - type: audit
          enabled: true
        - type: syslog
          enabled: false
          host: "siem.example.com"
          port: 6514
          protocol: tcp
          tls: true
          tls_skip_verify: false
          tls_cert_path: "/etc/tkadmin/secrets/siem_client.pem"
          tls_key_path: "/etc/tkadmin/secrets/siem_client.key"
          facility: 16
          tag: "tkadmin-aiddr"
          retry_max: 3
        - type: cef
          enabled: false
          target: syslog
          vendor: "TACHYON"
          product: "tkadmin"
        - type: webhook
          enabled: false
          url: "https://siem.example.com/ingest"
          hmac_secret: "${WEBHOOK_HMAC_SECRET}"
          timeout_seconds: 10
          retry_max: 3
경고

HMAC secret은 cfg 파일에 평문으로 쓰지 마십시오. ${WEBHOOK_HMAC_SECRET}처럼 환경변수로 주입하고, JSON 응답에는 노출되지 않습니다.

Syslog​

Syslog sink는 RFC 5424 구조화 데이터를 사용합니다. facility는 16~23 범위이며, 등급별 severity는 C=P0=Critical, S=P1=Warning, O=P2=Notice입니다. Structured Data에는 8자 UserHMAC prefix만 포함됩니다.

TCP/TLS Syslog 전송 실패 시 retry_max 범위 안에서 exponential backoff를 적용합니다. 기본 backoff는 1초에서 시작해 2배씩 증가하고 16초에서 cap 되며, ±20% jitter가 붙습니다. retry_max는 설정 검증 단계에서 0~10으로 clamp 되며 Syslog sink가 별도로 더 낮게 재클램프하지 않습니다. UDP는 손실 허용 전송이므로 재시도하지 않습니다.

Webhook + HMAC​

Webhook URL은 HTTPS만 허용됩니다. 요청 헤더 X-TKADMIN-Signature는 sha256=<hex> 형식입니다.

import hmac, hashlib

expected = "sha256=" + hmac.new(secret.encode(), body, hashlib.sha256).hexdigest()
assert hmac.compare_digest(expected, headers["X-TKADMIN-Signature"])

Dedup​

중복 억제 키는 (UserHMACPrefix 8자, Grade, ScenarioID)입니다. 기본 윈도우는 5분이고 같은 키는 첫 1건만 외부로 전송됩니다.
